# Milis Cosmo — Контент-завод (ИИ-автоматизация Reels)

Автопайплайн: тема из банка идей → сценарий (LLM) → видео с ИИ-аватаром (HeyGen) →
публичная ссылка на видео → **ваше утверждение в Telegram** → публикация в Instagram
(Meta Graph API) → отметка в трекере.

Режим по умолчанию — **автогенерация + ручное утверждение**: ничего не публикуется
без вашего "да" в Telegram-боте.

## Архитектура

```
run_pipeline.py  (запускается по расписанию, напр. cron 3 раза/нед)
   │
   ├─ 1. tracker.py            → берёт следующую тему из content_bank.yaml / xlsx-трекера
   ├─ 2. script_generator.py   → Claude API: тема → сценарий (хук/тело/CTA/подпись/хэштеги)
   ├─ 3. avatar_video.py       → HeyGen API: сценарий → видео с ИИ-аватаром + озвучкой
   ├─ 4. hosting.py            → загружает готовое видео на публичный URL (Cloudinary)
   ├─ 5. telegram_approval.py  → шлёт вам видео + текст, ждёт Одобрить/Отклонить
   ├─ 6. instagram_publish.py  → при одобрении публикует Reels через Graph API
   └─ 7. tracker.py            → проставляет статус "Опубликовано" + дату в xlsx
```

Каждый шаг — отдельный модуль, можно использовать по отдельности (например, только
генерацию сценариев без автопубликации).

## Что нужно настроить (один раз)

1. **Anthropic API key** — console.anthropic.com → для генерации сценариев
2. **HeyGen API key** — app.heygen.com (раздел API) → для генерации видео с аватаром.
   Заранее создайте/выберите аватар и голос в интерфейсе HeyGen, впишите их ID в конфиг.
3. **Cloudinary** (бесплатный тариф) — для публичного URL видео, обязателен для Instagram
   Graph API (он не принимает файлы напрямую, только ссылку)
4. **Telegram-бот** — создать через @BotFather, получить token, узнать свой chat_id
5. **Meta Graph API** — Instagram Business-аккаунт у вас уже подключён к Meta Business
   Suite. Нужно получить: `IG_BUSINESS_ACCOUNT_ID` и долгоживущий `ACCESS_TOKEN` с правами
   `instagram_content_publish`, `pages_show_list` через developers.facebook.com

Скопируйте `config.example.yaml` → `config.yaml`, впишите ключи. **`config.yaml` в
.gitignore — никогда не коммитьте его.**

## Установка

```bash
cd content_factory
pip install -r requirements.txt
cp config.example.yaml config.yaml   # и заполнить ключами
```

## Запуск

```bash
python run_pipeline.py --once          # сгенерировать 1 ролик и отправить на утверждение
python run_pipeline.py --daemon        # слушать ответы в Telegram, публиковать при "да"
```

Расписание генерации (например, пн/ср/пт/вс) — через cron на сервере:
```
0 10 * * 1,3,5,0  cd /path/content_factory && python run_pipeline.py --once
```

## Тарифы инструментов — три уровня (ориентир, уточняйте на сайтах — цены меняются)

| Уровень | Сценарии (Claude API) | Аватар+голос (HeyGen) | Хостинг видео | Итого/мес |
|---|---|---|---|---|
| **Минимум** | ~300–500 ₽ (мало токенов) | Free-тариф: 3 видео/мес, с водяным знаком | Cloudinary free | ~300–500 ₽ + ваше время на ручную публикацию |
| **Рекомендуемый старт** | ~300–500 ₽ | Creator ~$29/мес (≈2 700 ₽): без водяного знака, десятки видео/мес | Cloudinary free | ~3 000–3 500 ₽ |
| **Расширенный** | ~500–800 ₽ | Team/Scale ~$89–220/мес (≈8 300–20 000 ₽): больше аватаров, A/B | Cloudinary Plus (если превысите лимит) | ~9 000–21 000 ₽ |

Telegram-бот и Meta Graph API — бесплатны всегда. Рекомендация: начать с уровня
"Рекомендуемый старт" — это подписка, а не разовая крупная инвестиция, отменяется
в любой момент.

## Ограничения, которые нужно знать

- Instagram Graph API публикует **только** по публичной прямой ссылке на видео — поэтому
  в пайплайне есть шаг хостинга (Cloudinary), это не опция, а обязательное звено.
- HeyGen-аватар — это синтетическое лицо. Instagram/Meta требует по своим правилам
  раскрывать AI-генерированный контент, если он выглядит как реальный человек — в
  `script_generator.py` подпись автоматически добавляет пометку "Создано с ИИ" в конце,
  уберите на свой риск после юридической консультации (это не юридическая консультация).
- Долгоживущий Meta access token нужно обновлять примерно раз в 60 дней (ограничение
  самого API, не пайплайна).
- Каждый вызов HeyGen — платный по факту генерации (не только подписка ограничивает).
  Проверяйте баланс на app.heygen.com перед массовым запуском.
