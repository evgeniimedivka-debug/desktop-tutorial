# Автопубликация Milis Decor — Telegram + Instagram

Статус: **развёрнуто на живой инфраструктуре** (VPS 31.130.131.58, n8n +
NocoDB) в этой сессии, через прямой доступ по API (NocoDB personal token,
n8n API key). Файлы в этой папке — архивная копия того, что реально
включено, не шаблон для ручного импорта.

## Что сделано и уже работает

1. **NocoDB, таблица «Ролики»** (`pgcrh775xcev3n6` / `mbv0dd92dx4irfp`):
   - добавлены поля `Одобрено владельцем` (checkbox), `IG: Опубликовано`
     (checkbox), `IG media id`, `TG message id`;
   - в мультиселект `Канал` добавлена опция `Instagram`;
   - создан Gallery View **«Согласование»** (id `vw0211cpf1d3r800`),
     отфильтрован на `Статус = На согласовании` — это и есть отдельная
     инфраструктура для одобрения, без бота и без переписки.
2. **CF-02** (HeyGen webhook → согласование) — из карточки в Telegram
   убраны кнопки «Одобрить»/«Переделать», текст указывает согласовывать
   через NocoDB.
3. **CF-04** (Telegram callback) — убрана ветка автопубликации по
   нажатию кнопки (она всё равно больше не сработает без кнопок, но
   ветка удалена явно). Запись решения через callback оставлена
   (на случай, если где-то ещё остались кнопки) — сама публикация
   больше никак не зависит от Telegram.
4. **CF-08** — новый активный workflow в n8n (id `O4PnSZ0B0gmKyq2F`):
   по вебхуку от NocoDB читает запись, проверяет `Одобрено владельцем`,
   публикует видео в канал @MilisDecor (chat_id `-1003914664264`,
   уже подтверждённые права администратора у бота), помечает статус.
5. **CF-09** — новый workflow в n8n (id `XForOiIvITzVEYAK`), **неактивен**:
   публикация в Instagram по упрощённой схеме «Instagram API с входом
   через Instagram» (graph.instagram.com, без Facebook Page/Business
   Manager). Включится сам после того, как в окружении n8n появятся
   `IG_USER_ID` и `IG_ACCESS_TOKEN` — см. `instagram-setup-runbook.md`.

## Единственный оставшийся шаг — вручную, через UI (не через API)

NocoDB (версия 2026.09.0) отключила создание webhook через REST API
(`hook version is deprecated`), а новый API для этого — только на
Enterprise-лицензии. Это не мой отказ — это ограничение именно этой
версии, upgrade-путь у NocoDB есть, но сейчас доступен только UI.

**Что сделать (2 минуты, в браузере, в NocoDB):**
1. Таблица «Ролики» → правая панель Details → **Webhooks** → **New
   Webhook**.
2. Event: **After** → Operation: **Update**.
3. Condition: `Одобрено владельцем` = `true`.
4. URL: `https://n8n.31-130-131-58.sslip.io/webhook/cf/publish-telegram`.
5. Headers: `x-cf-secret` = то же значение, что уже используется для
   `/webhook/cf/render` (я его не читаю и не буду — я к секретам через
   Bash не притрагиваюсь, это сработавшая защита, а не моя прихоть).
6. Save. Потом то же самое для Instagram — тот же webhook, но
   Condition `Канал` содержит `Instagram`, URL
   `.../webhook/cf/publish-instagram` — включать только после того,
   как заработает CF-09.

После этого шага весь цикл «поставили галочку в NocoDB → видео ушло в
Telegram» будет полностью автоматическим.
