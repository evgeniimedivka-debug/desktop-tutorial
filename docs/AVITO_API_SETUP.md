# Настройка доступа к Avito API

## Получение credentials

1. Кабинет Avito → **Настройки → API** (или **Каталог API → Мои приложения**).
2. Создать приложение:
   - Название — любое рабочее.
   - Redirect URL — для серверной интеграции (используем ниже) не задействуется, подойдёт любая заглушка (`https://example.com`).
   - Назначение приложения — коротко опишите, что будете делать (цены/остатки, мессенджер, статистика).
3. Нажать «Запросить доступ» — заявку модерируют вручную, срок — уточнить в кабинете.
4. После одобрения в кабинете появятся `Client ID` и `Client Secret`.

## Хранение секретов

- Никогда не публикуйте `client_secret` и не вставляйте в переписку/issue/PR.
- Локально: `cp .env.example .env`, заполнить значениями, файл `.env` уже в `.gitignore`.
- Если секрет всё же засветился где-то (чат, скриншот, коммит) — перевыпустите его в кабинете немедленно.

## Проверка подключения

```bash
pip install -r requirements.txt
python examples/check_auth.py
```

Если видите `Авторизация успешна. Аккаунт: {...}` — интеграция настроена верно.

## Важно про версии эндпоинтов

Набор доступных методов API (Автозагрузка, Мессенджер, Статистика) зависит
от того, какие продукты включены для вашего аккаунта — это видно в разделе
«Каталог API» кабинета. Перед первым боевым запуском `avito_api/autoload.py`,
`avito_api/messenger.py`, `avito_api/stats.py` сверьте пути эндпоинтов и
структуру ответов с актуальной документацией в кабинете — в коде это
отмечено комментариями.

## Что уже реализовано

| Модуль | Возможности |
|---|---|
| `avito_api/auth.py` | OAuth2 client_credentials, автообновление токена |
| `avito_api/autoload.py` | Обновление цены/статуса объявления, статус отчёта автозагрузки |
| `avito_api/messenger.py` | Список чатов, чтение/отправка сообщений, простой автоответ |
| `avito_api/stats.py` | Просмотры/контакты/избранное по объявлениям за период |

## Дальнейшие шаги (не сделано, по мере необходимости)

- Вебхуки мессенджера вместо поллинга (реалтайм уведомления вместо периодического опроса).
- Персистентность для автоответов (не отвечать в один чат дважды).
- Планировщик (cron) для регулярного запуска `examples/sync_prices.py`.
