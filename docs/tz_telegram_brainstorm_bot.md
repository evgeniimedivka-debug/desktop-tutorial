# ТЗ: Telegram-бот для мозгового штурма (Евгений + Анна + AI)

## 1. Контекст и цель

Есть рабочая Telegram-группа Евгения (владелец бизнеса) и Анны (менеджер Ozon/ВК). Нужен бот-участник группы, который отвечает на обращения к себе (мозговой штурм, поиск решений по бизнесу), а не просто пересылает сообщения.

Бизнес-контекст (зашить в system prompt бота):
- **Milis Cosmo** — косметика собственного производства (масло для роста волос, масло усьмы для бровей/ресниц, сыворотка для ресниц, масло монарды, масло розмарина, крем-воск для пяток), продажи на Wildberries и Ozon с 2021 г.
- **Milis Decor** — ПУ-панели под скалу/камень, закупка в Китае, сбыт через магазин на Avito (тестируемая ниша).
- **art.Angel** — Bluetooth-адаптеры из Китая, продажи на Ozon (тот же магазин, где продаётся и Milis Cosmo на Ozon).
- Текущий фокус: маржинальность действующих карточек, новые каналы сбыта, соцсети/узнаваемость бренда.

Готовое ограничение: избегать решений, требующих крупных вложений на старте.

## 2. Архитектура

```
Telegram-группа (Евгений + Анна + бот @OzonAnnabot)
        │  сообщение с упоминанием бота ИЛИ ответ на его сообщение
        ▼
Telegram Bot API → webhook (POST)
        ▼
Pipedream workflow (HTTP-триггер)
        ▼
Node.js code step → Anthropic Messages API (Claude)
        ▼
Node.js code step → Telegram sendMessage (ответ в группу)
```

Бот отвечает ТОЛЬКО когда:
- сообщение содержит упоминание `@OzonAnnabot`, ИЛИ
- сообщение — reply на предыдущее сообщение бота.

Это сделано намеренно (privacy mode Telegram-бота по умолчанию и так фильтрует остальные сообщения группы) — чтобы не отвечать на каждую реплику между Евгением и Анной и не тратить API-бюджет впустую.

Используется существующий бот **@OzonAnnabot** (токен уже есть, создан 14.09.2026 для пересылки эскалаций Ozon-бота Анне) — отдельного бота заводить не нужно, но в коде должна быть проверка `chat.id`, чтобы логика мозгового штурма срабатывала только в НОВОЙ группе, а не в личке с Анной (там у бота другая роль — пересылка вопросов Ozon).

## 3. Пошаговые задачи

### 3.1. Подготовка (ручные шаги, не для Claude Code — уже сделаны/в процессе владельцем)
- [x] Бот @OzonAnnabot создан, токен есть.
- [ ] Бот добавлен в новую Telegram-группу с Евгением и Анной.
- [ ] В группе отправлено тестовое сообщение с упоминанием бота — из него получен `GROUP_CHAT_ID` через `getUpdates`.
- [ ] Аккаунт на pipedream.com зарегистрирован.
- [ ] Ключ Anthropic API получен на console.anthropic.com.

### 3.2. Реализация (задача для Claude Code / разработчика)
1. Создать Pipedream workflow с HTTP-триггером, получить URL.
2. Вызвать `setWebhook` Telegram Bot API на этот URL (curl-команда, см. раздел 5).
3. Реализовать Node.js code step по спецификации из раздела 4.
4. Настроить переменные окружения в Pipedream: `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY`, `GROUP_CHAT_ID`.
5. Протестировать: сообщение с упоминанием бота в группе → ответ приходит в течение нескольких секунд как reply на исходное сообщение.
6. Проверить, что бот НЕ отвечает на сообщения без упоминания/reply, и НЕ реагирует на сообщения в личном чате с Анной (там работает отдельная логика Ozon-эскалаций, её не трогать).

## 4. Спецификация кода (Node.js step в Pipedream)

```js
import Anthropic from "@anthropic-ai/sdk";

export default defineComponent({
  async run({ steps, $ }) {
    const update = steps.trigger.event.body;
    const msg = update.message;
    if (!msg || !msg.text) return;

    // Работаем только в целевой группе мозгового штурма, не в личке с Анной
    if (String(msg.chat.id) !== String(process.env.GROUP_CHAT_ID)) return;

    const botUsername = "OzonAnnabot";
    const isMention = msg.text.includes(`@${botUsername}`);
    const isReplyToBot = msg.reply_to_message?.from?.is_bot === true;
    if (!isMention && !isReplyToBot) return;

    const anthropic = new Anthropic({ apiKey: process.env.ANTHROPIC_API_KEY });

    const systemPrompt = `Ты — участник мозгового штурма в рабочем чате Евгения (владелец) и Анны (менеджер Ozon/ВК).
Бизнес: Milis Cosmo (косметика собственного производства, WB/Ozon), Milis Decor (ПУ-панели, Avito), art.Angel (блютус-адаптеры, Ozon).
Текущий фокус: маржинальность карточек, новые каналы сбыта, соцсети/узнаваемость бренда. Избегай советов, требующих крупных вложений на старте.
Роль — предлагать идеи и решения, задавать уточняющие вопросы, по-деловому и кратко (буллиты, без длинных вступлений).
Никогда не публикуй, не отправляй сообщения от их имени и не называй точные суммы без пометки «уточнить» — только советуй в этом чате.`;

    let replyText;
    try {
      const response = await anthropic.messages.create({
        model: "claude-sonnet-4-5", // проверить актуальный ID модели в docs.claude.com перед деплоем
        max_tokens: 1024,
        system: systemPrompt,
        messages: [{ role: "user", content: `${msg.from.first_name}: ${msg.text}` }],
      });
      replyText = response.content[0].text;
    } catch (e) {
      console.log(`[warn] Anthropic API error: ${e.message}`);
      return; // не отвечаем молчанием при ошибке, не роняем workflow
    }

    await fetch(`https://api.telegram.org/bot${process.env.TELEGRAM_BOT_TOKEN}/sendMessage`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        chat_id: msg.chat.id,
        text: replyText,
        reply_to_message_id: msg.message_id,
      }),
    });
  },
});
```

## 5. Настройка webhook (выполнить один раз после получения URL от Pipedream)

```bash
curl -X POST "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook" \
  -d "url=<PIPEDREAM_WORKFLOW_URL>"
```

Проверка текущего статуса вебхука в любой момент:
```bash
curl "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/getWebhookInfo"
```

## 6. Нефункциональные требования

- **Секреты**: токен бота и ключ Anthropic — только в переменных окружения Pipedream, нигде не хардкодить в коде, нигде не публиковать.
- **Стоимость**: Anthropic API — платный по факту использования (отдельный биллинг от подписки Claude.ai), Pipedream — бесплатный тариф достаточен для этой нагрузки. Точную сумму расходов заранее не оценивать — зависит от объёма переписки, уточнять по факту первого счёта.
- **Отказоустойчивость**: ошибка вызова Anthropic API не должна ронять workflow — просто лог и без ответа в чат (см. try/catch в коде).
- **Разграничение с Ozon-ботом**: логика мозгового штурма должна проверять `chat.id` и срабатывать только в группе, не задевая личку с Анной, где тот же бот используется для пересылки эскалаций Ozon-вопросов (эта логика — на стороне scheduled-задачи Ozon-бота, не в этом workflow, дублировать не нужно).

## 7. Известные ограничения v1 (не блокируют запуск)

- Бот не хранит историю переписки — каждый ответ строится без контекста предыдущих сообщений в группе. Добавление памяти (хранение последних N сообщений через Pipedream Data Store) — задача v2, делать только если понадобится по факту использования.
- Нет ограничения по частоте/бюджету запросов к Anthropic API — при активном использовании стоит на v2 добавить простой rate-limit (например, не более N ответов в час).

## 8. Критерии готовности (definition of done)

- [ ] Сообщение с `@OzonAnnabot` в группе получает ответ в течение ~5-10 сек.
- [ ] Reply на сообщение бота тоже получает ответ.
- [ ] Сообщения без упоминания/reply бот игнорирует.
- [ ] Сообщения в личном чате с Анной эту логику не затрагивают (Ozon-эскалации продолжают работать как раньше).
- [ ] Токены и ключи не встречаются в коде в открытом виде, только в env vars Pipedream.
